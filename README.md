# 🕐 Digital Clock

A simple and responsive Digital Clock built using HTML, CSS, and JavaScript. This project displays the current time, day, and date in a clean and minimal interface.

## ✨ Features

* 🕐 Displays the current time
* 📅 Displays the current date
* 📆 Displays the current day
* ⚡ Updates the time automatically
* 📱 Responsive design
* 🎨 Simple and minimal UI

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* DOM Manipulation
* CSS Flexbox
* Media Queries

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone YOUR-REPOSITORY-LINK
```

2. Open the project folder:

```bash
cd digital-clock
```

3. Open `index.html` in your browser.
